# Zeropense

A personal expense tracker that reads your bank SMS and turns them into transactions — on the phone,
with no account, no cloud and no ads. Built for AED and INR.

**This branch is the native Android (Kotlin, Jetpack Compose) rebuild, in progress.** It is built one feature
at a time following [`docs/TODO.md`](docs/TODO.md); the behaviour is specified in [`docs/FSD.md`](docs/FSD.md).

The original React Native / Expo app is preserved on the
[`backup/expo-react-native`](https://github.com/najeem99/Zeropense/tree/backup/expo-react-native) branch.
`apk/Zeropense.apk` is still the Expo build until the native release (F20) replaces it.
